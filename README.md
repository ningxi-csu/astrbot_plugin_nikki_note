# astrbot_plugin_nikki_note

无限暖暖 · 奇想手账日程查询插件（AstrBot 插件）

每位群友绑定自己的叠纸账号，随时在群聊或私聊中查看自己奇想手账的**能量、心愿、挖掘、幻境**等日程状态，也可以一键查看**账号数据、探索总览、奇想札记、奇迹之冠**，以及各卡池套装的**共鸣次数、集齐状态和最高进化**，无需再打开游戏或网页。

## 功能特性

- **每人独立绑定**：用户私聊机器人，通过「手机号 + 短信验证码」或「账号 + 密码」绑定自己的叠纸通行证账号，登录态按 QQ 号隔离保存
- **一键查日程**：群聊/私聊发送 `/暖暖日程`，实时返回能量恢复进度、心愿、挖掘队列、幻境挑战状态
- **账号总览**：发送 `/暖暖总览`，以 Markdown 返回账号数据、探索总览（收集进度按 `已收集/总数` 展示）、奇想札记与奇迹之冠
- **卡池查询**：按套装简称、版本、版本双四或常驻池查询，返回每套套装的平均/总计共鸣次数、是否集齐和最高已拥有进化
- **登录态自动续期**：token 过期时自动使用 refresh_token 换新，有效期约 60 天，续期失败才提示重新绑定
- **请求节流保护**：数据缓存 60 秒、每人查询冷却 10 秒、验证码发送冷却 60 秒，避免群友高频查询放大请求
- **隐私友好**：手机号和验证码仅在私聊中处理，登录态仅保存在机器人本地的插件 `data` 目录

## 指令一览

| 指令 | 使用场景 | 说明 |
| --- | --- | --- |
| `/暖暖帮助` | 群聊/私聊 | 查看插件用法 |
| `/暖暖绑定 手机号` | 仅私聊 | 发送登录短信验证码 |
| `/暖暖验证码 验证码` | 仅私聊 | 提交验证码，完成绑定 |
| `/暖暖密码登录 账号 密码` | 仅私聊 | 账号密码直接绑定（手机号/邮箱） |
| `/暖暖日程` | 群聊/私聊 | 查看自己的日程 |
| `/暖暖总览` | 群聊/私聊 | 查看账号数据、探索总览、奇想札记、奇迹之冠 |
| `/查询卡池 蝴蝶套` | 群聊/私聊 | 查询指定简称对应的限定五星套装 |
| `/查询卡池 1.0` | 群聊/私聊 | 查询该版本限定五星及同卡池陪跑四星 |
| `/查询卡池 1.0双四` | 群聊/私聊 | 查询该版本的两套双四星套装 |
| `/查询卡池 常驻` | 群聊/私聊 | 查询常驻池四套五星和四套四星 |
| `/暖暖解绑` | 仅私聊 | 解除绑定并删除本地登录态 |

卡池指令中的空格可以省略，例如 `/查询卡池蝴蝶套`。版本号可替换为 `1.0`～`2.11` 中已收录的卡池版本；简称末尾的“套”可省略，也支持直接输入完整套装名。

套装简称包括：蝴蝶、精灵、纸鹤、烟花、气球、八音盒、玩偶、鱼、鸟、教母、蛇、龙、猫、歌剧、女巫、哥特、圣女、神女、萤火虫、扇、鹿、独角兽、小红帽、骨、花、竖琴、水花、芭蕾、狮鬃、香妃、埃及、圣诞、玫瑰。

共鸣统计与奇想手账网页一致：每个部件最多统计前两次出货，累加距上次同星级出货的间隔；平均共鸣次数为总间隔除以实际命中部件次数。五星最高显示套装进化 3，四星最高显示套装进化 1，未拥有进化时显示 0。

## 使用流程

**方式一：短信验证码绑定**

1. **私聊**机器人发送：`/暖暖绑定 13800138000`
2. 收到短信后回复：`/暖暖验证码 123456`（验证码 3 分钟内有效）
3. 绑定成功后在群聊或私聊发送：`/暖暖日程`

**方式二：账号密码绑定（免验证码）**

1. **私聊**机器人发送：`/暖暖密码登录 13800138000 mypassword`（账号支持手机号或邮箱）
2. 绑定成功后在群聊或私聊发送：`/暖暖日程`

## 安装方式

### 方式一：AstrBot 插件市场（推荐）

在 AstrBot 管理面板的插件市场中搜索 `astrbot_plugin_nikki_note`，点击安装即可。

### 方式二：手动安装

```bash
cd /path/to/AstrBot/data/plugins
git clone https://github.com/你的用户名/astrbot_plugin_nikki_note.git
```

然后在 AstrBot 管理面板重载插件（或重启 AstrBot），依赖会自动安装。

## 数据文件说明

插件运行后会在 AstrBot 的 `data/plugin_data/astrbot_plugin_nikki_note/` 目录生成以下文件（符合插件上架规范，便于数据迁移与审计）：

| 文件 | 作用 | 备注 |
| --- | --- | --- |
| `data/plugin_data/astrbot_plugin_nikki_note/users.json` | 各 QQ 号的登录态（nid / token / refresh_token） | 含敏感信息，请勿泄露 |
| `data/plugin_data/astrbot_plugin_nikki_note/device.json` | 通行证设备标识（DOID / web_deviceid） | 必须保持稳定，删除会导致已发验证码失效，请勿手动删除 |

> 从旧版本升级：把原插件目录 `data/` 下的 `users.json` 和 `device.json` 移动（不要复制后再保留旧文件）到上述目录即可，已绑定的账号和发了验证码的设备标识都能继续使用。

## 常见问题

**Q：验证码明明正确，绑定却提示失败（1005）？**
通行证接口校验设备标识，发送验证码和登录必须使用同一个 DOID / web_deviceid。本插件已自动持久化设备标识，请不要在绑定流程中途删除 `device.json`。

**Q：登录态会过期吗？**
token 过期时会自动用 refresh_token 续期，整体有效期约 60 天。仅当 refresh_token 也失效时才会提示重新绑定。

**Q：手机号会被泄露吗？**
绑定指令仅允许私聊使用；登录态只保存在机器人服务器的 `data/plugin_data/astrbot_plugin_nikki_note/` 目录，不会上传到任何第三方。
